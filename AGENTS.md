# Wanderlust

Single Next.js 16 / React 19 / TypeScript app (App Router). No monorepo, no tests, no CI. The app is a destinations-CRUD exercise (`src/app/page.tsx` is the lone, mostly-empty entrypoint); destination images live in `public/destinations/`.

## Commands

- `npm run dev` — dev server; also generates `.next/dev/types/**` required by tsconfig
- `npm run build` — production build
- `npm run lint` — bare `eslint` (Next 16 dropped `next lint`); no typecheck script exists — use `npx tsc --noEmit`
- Fresh clone gotcha: `tsc --noEmit` fails until `next dev` or `next build` has run once, because tsconfig includes `.next/*` generated types (these enable typed route/props helpers like `LayoutProps<"/">`)
- Practical order: `npm run lint` → `tsc --noEmit` → `npm run build`

## Stack quirks that change how you write code

- **React Compiler is enabled** (`reactCompiler: true` in `next.config.ts`): do not add `useMemo`/`useCallback`/manual memoization; keep components pure during render — the compiler assumes Rules of React compliance.
- **shadcn "base-nova" style** is pre-scaffolded into `src/components/ui` — built on `@base-ui/react`, **not** Radix. Don't paste Radix-based shadcn snippets from training data; read an existing `src/components/ui/*.tsx` first to match the Base UI API. Add new components via the `shadcn` CLI (config in `components.json`, aliases resolve `@/*` → `src/*`).
- `cn` is a one-line re-export of the `cn` package from `@/lib/utils` — always use the `@/lib/utils` import path.
- **Tailwind v4, no `tailwind.config.js`** — theme tokens/customization live in `src/app/globals.css` (see `components.json` `tailwind.css`). Turbopack handles CSS via the rule in `next.config.ts`.
- Typography: Josefin Sans loads via `next/font` in `src/app/layout.tsx` and is applied as a plain `className` on `<html>` (no CSS variable wiring).
- `experimental.agentFeedback: true` in `next.config.ts` powers this file — keep it on.
